# Приёмка в Revit 2026

Статус: **требует выполнения на машине с установленным Revit**. Компиляция API-адаптера и CLI-тесты не подтверждают загрузку внутри Autodesk-хоста.

## Подготовка

1. Использовать Windows x64 и Revit 2026; желательно обновление 2026.4 или новее, соответствующее используемым reference-пакетам.
2. Выполнить `scripts/Package.ps1` и `scripts/Install-Addin.ps1` при закрытом Revit.
3. Запустить Revit и при необходимости самостоятельно подтвердить загрузку доверенного локального плагина.
4. Убедиться, что на вкладке «Надстройки» появилась панель **BIM Guard** с тремя кнопками.

## Сценарии

| Шаг | Действие | Ожидаемый результат |
| --- | --- | --- |
| 1 | Не открывать проект / открыть семейство | Команды недоступны |
| 2 | Создать новый пустой архитектурный проект | Команды доступны |
| 3 | Нажать «Создать демо-фрагмент», выбрать «Нет» | Модель не изменена |
| 4 | Повторить, выбрать «Да» | Созданы уровень BG DEMO, четыре стены и два помещения |
| 5 | Нажать «Проверить модель» | Открылось WPF-окно; в стандартном шаблоне проверено 6 элементов |
| 6 | Просмотреть замечания | Есть пустая марка стены, два дубликата BG-W01 и неразмещённое помещение |
| 7 | Выбрать размещённую стену → «Показать в Revit» | Окно закрывается, стена выделяется и показывается |
| 8 | Повторить переход для неразмещённого помещения | Нет аварии; элемент выбран или выдано понятное сообщение о невозможности показа |
| 9 | Экспортировать CSV и JSON | Кириллица читается, ID и коды правил совпадают с отчётом |
| 10 | Выгрузить JSON-снимок | Снимок читается CLI и демоприложением |
| 11 | Исправить пустую/повторную марки; удалить либо разместить неразмещённое помещение в отдельной замкнутой зоне | После новой проверки соответствующие замечания исчезают |
| 12 | Открыть историю | Старый отчёт сохраняет прежние замечания, новый отражает изменения |
| 13 | Перейти к элементу, удалённому после старой проверки | Показано сообщение об отсутствии элемента |
| 14 | Повторно запустить создание демо-фрагмента в заполненной модели | Команда отказывается добавлять данные |
| 15 | Проверить модель до и после аудита | Проверка и экспорт не меняют параметры/геометрию |
| 16 | В отдельном новом проекте создать фрагмент и выполнить Undo | Весь фрагмент отменяется одним действием |

Точный набор замечаний демо-фрагмента зависит от шаблона и расчёта границ помещений. Для стандартного шаблона ожидаются 2 ошибки и 3 предупреждения; эти числа ещё не подтверждены фактическим запуском в Revit. Воспроизводимый JSON-пример из репозитория имеет другой набор: 11 элементов, 4 ошибки, 4 предупреждения.

## Зафиксировать результат

Записать сборку Revit, шаблон, версию .NET, версию плагина, фактические счётчики, скриншоты и результат каждого сценария. Проверить русский и английский интерфейсы Revit, а также модель с фазами и вариантами.

При проблеме сохранить журнал `%LOCALAPPDATA%/BimGuard/errors.log` и минимальный JSON-снимок без конфиденциальных данных. До распространения плагина отметить выполненные сценарии в протоколе.
