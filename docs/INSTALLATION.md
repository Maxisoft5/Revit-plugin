# Установка BIM Guard

## Требования

Для плагина:

- Windows x64.
- Autodesk Revit 2026. Рекомендуется обновление 2026.4 или новее, соответствующее API-ссылкам сборки.
- Доступ на запись в пользовательские каталоги AppData.

.NET 8 предоставляется установкой Revit. SDK .NET нужен только для сборки из исходников.

Для автономного WPF-приложения нужен .NET 8 Desktop Runtime. Скрипт запуска также допускает установленный более новый совместимый runtime через Major roll-forward.

## Установка готового пакета

1. Закройте Revit.
2. Распакуйте `BimGuard-Revit2026.zip` в отдельную папку.
3. Откройте PowerShell в этой папке и выполните:

```powershell
.\Install-Addin.ps1
```

4. Запустите Revit. При запросе загрузки локального плагина подтвердите её.
5. Проверьте наличие панели **BIM Guard** на вкладке «Надстройки».

Скрипт устанавливает приложение для текущего пользователя. Права администратора не требуются.

| Назначение | Каталог |
| --- | --- |
| DLL и зависимости плагина | `%LOCALAPPDATA%/BimGuard/Revit2026` |
| Манифест загрузки | `%APPDATA%/Autodesk/Revit/Addins/2026/BimGuard.addin` |
| История проверок | `%LOCALAPPDATA%/BimGuard/history.db` |
| Журнал ошибок | `%LOCALAPPDATA%/BimGuard/errors.log` |

Для предварительного просмотра действий:

```powershell
.\Install-Addin.ps1 -WhatIf
```

## Сборка пакета из исходников

Из корня репозитория:

```powershell
.\scripts\Package.ps1
.\scripts\Install-Addin.ps1
```

Скрипт упаковки сначала собирает решение и запускает тесты. Результат:

- `artifacts/revit-2026/` — содержимое установочного пакета.
- `artifacts/BimGuard-Revit2026.zip` — архив для установки.

API-сборки Autodesk в пакет не включаются. Нативная x64-библиотека SQLite поставляется рядом с DLL плагина.

## Обновление

Закройте Revit и повторите установку нового пакета. Пользовательская история находится отдельно от DLL и сохраняется при обновлении.

## Удаление

При закрытом Revit удалите:

1. `%APPDATA%/Autodesk/Revit/Addins/2026/BimGuard.addin`.
2. `%LOCALAPPDATA%/BimGuard/Revit2026`.

Файл истории `history.db` можно оставить для последующей установки. Для полного удаления данных отдельно удалите каталог `%LOCALAPPDATA%/BimGuard`.

## Если панель не появилась

- Проверьте, что пакет установлен в каталог Addins именно для Revit 2026.
- Откройте `BimGuard.addin` и проверьте существование DLL по пути `Assembly`.
- Убедитесь, что рядом с DLL находятся зависимости SQLite и остальных модулей приложения.
- Перезапустите Revit после установки.
- Проверьте журнал ошибок и выполните [приёмочные сценарии](REVIT-ACCEPTANCE.md).
