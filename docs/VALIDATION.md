| Параметр | Значение |
| --- | --- |
| ОС | Windows x64 |
| SDK | .NET 10.0.400 |

## Пакет и установка

```powershell
.\scripts\Package.ps1 -SkipTests
```

Пакет собран после полного прогона. Проверены наличие нативной x64-библиотеки SQLite и отсутствие API DLL Autodesk.

Установочный скрипт выполнен с отдельными каталогами `artifacts/install-smoke` через параметры `-InstallPath` и `-AddinsRoot`. Сформированный манифест указывает на существующую DLL. Регистрация в каталоге загрузки Revit не выполнялась.
