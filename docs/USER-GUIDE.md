# Руководство пользователя

## Проверка модели

1. Откройте проект Revit.
2. На вкладке «Надстройки» найдите панель **BIM Guard**.
3. Нажмите **«Проверить модель»**.
4. Просмотрите список замечаний и итоговые счётчики.

Команда проверяет экземпляры стен, перекрытий, дверей, окон и помещений. Типы элементов и связанные модели в проверку не включаются. В редакторе семейств и при отсутствии открытого проекта команды недоступны.

Проверка читает данные модели и сохраняет отчёт в локальную историю.

## Окно отчёта

В верхней части показаны название документа, время проверки, число проверенных элементов, ошибок и предупреждений.

В таблице замечаний доступны:

| Поле | Содержание |
| --- | --- |
| Код | Идентификатор правила BG001–BG004 |
| Важность | Ошибка или предупреждение |
| ID | Числовой идентификатор элемента Revit |
| Элемент | Имя элемента |
| Категория | Категория проверяемого экземпляра |
| Описание | Причина замечания |

Выберите строку, чтобы прочитать полное описание и UniqueId в нижней части окна.

## Поиск и фильтры

Поиск работает по коду правила, ID элемента, категории, имени и описанию. Регистр символов не учитывается. Например:

- `BG004` — замечания о площади помещений.
- `Walls` — замечания к стенам.
- `201` — поиск по ID.
- `марка` — поиск по тексту описания.

Фильтр важности оставляет все замечания, только ошибки или только предупреждения. Поиск и важность применяются одновременно.

Сводные счётчики относятся ко всему отчёту. Число строк после фильтрации отображается отдельно. При изменении фильтра выбранное замечание сбрасывается.

## Переход к элементу

Выберите замечание и нажмите **«Показать в Revit»**. Окно отчёта закроется; приложение попытается выделить и показать элемент.

Если элемент удалён, появится сообщение об отсутствии. Неразмещённое помещение может быть недоступно для показа на виде. В автономном режиме кнопка перехода отключена.

## История

Откройте вкладку **«История проверок»**, выберите запись и нажмите **«Открыть выбранный отчёт»**.

Отображаются последние 50 запусков текущего документа. Загрузка истории не запускает новую проверку и сбрасывает фильтры. Старый отчёт отражает состояние модели на момент сохранения; после редактирования модели выполните новый аудит.

История хранится в `%LOCALAPPDATA%/BimGuard/history.db`.

## Экспорт отчёта

Кнопки **«Экспорт CSV»** и **«JSON»** сохраняют текущий полный отчёт. Поиск и фильтр важности не ограничивают выгрузку.

CSV использует UTF-8 с BOM и разделитель `;`. Поля с разделителями и кавычками экранируются. Значения, которые Excel может принять за формулу, сохраняются как текст.

JSON содержит идентификатор запуска, документ, время, число элементов и полный список замечаний.

## JSON-снимок модели

Команда **«Экспорт снимка»** на панели Revit сохраняет исходные данные проверки. Снимок можно открыть в автономном приложении или проверить через CLI. Он содержит метаданные документа и параметры поддерживаемых элементов; геометрия RVT не экспортируется.

Запуск автономного приложения из исходников:

```powershell
.\scripts\Run-Demo.ps1 -ModelPath '--open'
```

Без параметров открывается включённый пример с 11 элементами, 4 ошибками и 4 предупреждениями.

## Тестовый фрагмент

Команда **«Создать демо-фрагмент»** предназначена для проверки работы плагина в новом пустом проекте. После подтверждения она создаёт уровень, четыре стены и два помещения. В данных намеренно оставлены пустая марка, повторяющиеся марки и неразмещённое помещение.

Команда изменяет модель в одной транзакции. При наличии поддерживаемых архитектурных элементов она отказывается добавлять фрагмент. Используйте отдельный проект для проверки, затем запустите аудит.

## Интерпретация замечаний

- **BG001:** заполните марку экземпляра или номер помещения, если это предусмотрено BIM-стандартом.
- **BG002:** проверьте, допустимо ли повторение марки в данной категории.
- **BG003:** проверьте привязку элемента к уровню.
- **BG004:** проверьте размещение помещения и замкнутость его границ.

После исправлений запустите проверку повторно. Изменения в модели не обновляют ранее сохранённые отчёты автоматически.

Известные ограничения и статус приёмки приведены в [README](../README.md) и [протоколе проверок](VALIDATION.md).
